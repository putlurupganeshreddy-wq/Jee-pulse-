# JEE PULSE

Track. Test. Improve. Repeat.

A JEE preparation tracker (tests, syllabus, analytics, backup). Runs fully in the browser; data is stored locally in IndexedDB.

## Deploy on GitHub Pages
1. Create a repo and upload all files in this folder (keep `index.html` at the root).
2. Repo **Settings → Pages → Branch: main / root → Save**.
3. Open the URL GitHub shows (https://USERNAME.github.io/REPO/).

Also works on Netlify (drag the folder) or Vercel.

## Backup
Data lives only in your browser. Use **More → Export JSON** regularly.
